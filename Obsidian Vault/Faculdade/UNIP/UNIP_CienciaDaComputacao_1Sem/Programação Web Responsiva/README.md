# Programação Web Responsiva

Este diretório contém notas, exercícios e referências sobre desenvolvimento de páginas web que se adaptam a diferentes tamanhos de tela (mobile‑first, grid, flexbox, media queries, etc.).

> **Sugestões de conteúdo**
> - Conceitos de design responsivo
> - Frameworks CSS (Bootstrap, Tailwind)
> - Práticas de acessibilidade
> - Projetos de exemplo
