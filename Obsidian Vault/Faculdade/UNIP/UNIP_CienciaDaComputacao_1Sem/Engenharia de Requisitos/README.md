Notas e referências sobre análise, elicitação, documentação e gestão de requisitos de software.

> **Conteúdo sugerido**
> - Técnicas de elicitação (entrevistas, questionários)
> - Modelos de requisitos (casos de uso, histórias de usuário)
> - Qualidade de requisitos (clareza, consistência, testabilidade)
> - Ferramentas de gerenciamento (Jira, Trello, ReqIF)
