# Tópicos de Matemática Aplicada

Notas e exercícios que abordam aplicações da matemática em computação: modelagem, algoritmos, análise de complexidade, otimização e estatística.

> **Conteúdo sugerido**
> - Modelagem matemática de problemas computacionais
> - Algoritmos de otimização linear e não‑linear
> - Probabilidade e estatística para ciência de dados
> - Análise de complexidade de algoritmos
