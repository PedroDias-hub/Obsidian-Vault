# Roadmap especialista

## 1. Domínio da linguagem

Sintaxe → tipos → funções → classes → templates → STL → Modern C++.

## 2. Domínio da memória

Pointers → lifetime → ownership → RAII → allocators → object model.

## 3. Domínio do desempenho

Complexidade → cache → profiling → SIMD → concorrência → otimização.

## 4. Domínio de sistemas

OS → processos → threads → networking → hardware → embarcados.

## 5. Domínio avançado

Templates → concepts → constexpr → metaprogramação → coroutines → modules.

## 6. Engenharia

CMake → Git → testes → CI → arquitetura → segurança → manutenção.

## 7. Especialização

Escolher uma trilha:

- Embedded;
- Games;
- Graphics;
- Backend;
- Systems;
- Quant;
- Robotics;
- Scientific Computing;
- Compilers;
- High Performance Computing.

## Critério de domínio

Você deve conseguir explicar não só **como** usar um recurso, mas **por que**, **quanto custa**, **quais são seus riscos** e **quais alternativas existem**.
