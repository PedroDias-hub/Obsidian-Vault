# Objetivos do C++

## Por que C++ existe?

C++ busca combinar:

- abstração de alto nível;
- controle de baixo nível;
- desempenho;
- portabilidade;
- programação genérica;
- orientação a objetos;
- metaprogramação;
- acesso direto a recursos do sistema.

## Onde C++ é usado?

- sistemas operacionais;
- engines gráficas;
- jogos;
- sistemas embarcados;
- robótica;
- aplicações financeiras;
- computação científica;
- bancos de dados;
- navegadores;
- servidores;
- infraestrutura;
- aplicações de alta performance.

## Mentalidade

C++ permite escrever código extremamente eficiente, mas também permite cometer erros graves de memória, concorrência e gerenciamento de recursos.

Dominar C++ significa entender tanto a abstração quanto o que acontece por baixo dela.
