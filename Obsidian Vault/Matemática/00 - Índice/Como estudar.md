# Como estudar Cálculo

Para cada assunto, tente seguir esta sequência:

1. **Conceito** — explique com suas próprias palavras.
2. **Interpretação** — entenda o significado geométrico/físico.
3. **Definição** — registre a definição matemática.
4. **Fórmulas** — coloque as fórmulas importantes.
5. **Exemplo** — resolva pelo menos um exemplo.
6. **Exercícios** — faça exercícios sem consultar a solução.
7. **Erros comuns** — registre onde você errou.
8. **Conexões** — ligue a nota a outros conceitos usando `[[links]]`.

## Regra prática

Não use a nota de fórmulas como substituto da teoria. Fórmula deve responder **como calcular**; a teoria deve responder **por que funciona**.

## Estrutura de uma nota

```markdown
# Assunto

## Conceito

## Intuição

## Definição

## Fórmulas

## Exemplos

## Aplicações

## Erros comuns

## Exercícios

## Conexões
```
