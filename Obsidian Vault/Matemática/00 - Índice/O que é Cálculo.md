# O que é Cálculo?

Cálculo é uma área da matemática usada para estudar:

- variação
- movimento
- crescimento
- acumulação
- áreas e volumes
- otimização

Os dois conceitos fundamentais são:

1. Derivada → estuda taxas de variação
2. Integral → estuda acumulação

A derivada pergunta:

"Com que velocidade algo está mudando?"

A integral pergunta:

"Quanto foi acumulado?"
