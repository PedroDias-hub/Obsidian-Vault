## 🔧 Exemplo prático

**Derivada de uma função polinômica**

Considere a função  
\[ f(x) = 3x^{4} - 5x^{2} + 2x - 7 \]

Aplicando a regra de potência $\frac{d}{dx} x^{n} = n x^{n-1}$:

\[ \begin{aligned}
 f'(x) &= 3 \cdot 4 x^{3} - 5 \cdot 2 x^{1} + 2 \cdot 1 x^{0} - 0 \\
       &= 12x^{3} - 10x + 2.
\end{aligned} \]

> **Resultado:** $f'(x) = 12x^{3} - 10x + 2$

Esse tipo de exercício aparece em todas as notas de *Funções polinomiais*.

## 📐 Tabela de fórmulas

Confira a pasta **[Fórmulas](/Matemática/Fórmulas)** para tabelas completas, e aqui estão as mais usadas em Cálculo 0:

| Categoria | Fórmula | Comentário |
|---|---|---|
| Derivadas | $\displaystyle \frac{d}{dx} x^{n} = n x^{n-1}$ | Regra de potência |
| Integrais | $\displaystyle \int x^{n}\,dx = \frac{x^{n+1}}{n+1}+C$ ( $n\neq -1$ ) | Antiderivada básica |
| Limites | $\displaystyle \lim_{x\to a} \frac{f(x)-f(a)}{x-a}=f'(a)$ | Definição de derivada |
| Trigonometria | $\sin^{2}x+\cos^{2}x = 1$ | Identidade fundamental |
